## Rechte-Checkliste anzeigen

Zusätzlich zur interaktiven Abfrage enthält der Ordner die zentrale Datenbasis
`rechts_checkliste.py`:

```bash
python uhrheberrecht/rechts_checkliste.py
```

Die dargestellten Punkte sind keine automatische Rechtsfreigabe. Die Anwendung
zeigt nur Prüffragen zu Lizenz, Plattformfunktionen, Zitat- und Pastiche-Kontext
sowie Quellenhinweisen. Bei Unsicherheit vor Veröffentlichung qualifizierte
urheberrechtliche Beratung einholen.
